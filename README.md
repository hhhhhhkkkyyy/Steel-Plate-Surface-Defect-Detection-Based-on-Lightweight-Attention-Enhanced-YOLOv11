# Steel-Plate-Surface-Defect-Detection-Based-on-Lightweight-Attention-Enhanced-YOLOv11
本研究紧密围绕“高精度、轻量化、适配小样本”这一核心目标，深入展开了多项研究工作，具体如下： 模型结构创新方面：精心设计了一种轻量化的CBAM（Convolutional Block Attention Module，卷积块注意力模块）注意力机制。这一机制被巧妙地嵌入到YOLO11m骨干网络的关键特征提取模块之中。通过这样的方式，能够显著增强模型对缺陷区域的关注程度，从而有效提升模型对于那些难以察觉的小缺陷以及低对比度缺陷的识别能力。这种创新性的结构设计，为提高整个模型的性能奠定了坚实的基础。
